# LUX.BOX prototype

## Language — this project only

Everything here is in **English**: file names, identifiers, comments, docstrings, commit
messages, and the conversation about this project. Set by Pixun on 2026-09-23, in his
words: *"solo necesito que luxbox este compleetamente en ingles, y seguiremos en ingles"*
and *"la regla solo para este proyecto"* — it does **not** apply to his other projects,
where the standing rule (answer in the language of his message) still holds.

The Blender scene `luxbox_realtime.blend` keeps its original Catalan object names, because
that is the file he works in. `tools/prepare_export.py` renames them on export, so the GLB
and everything the web code looks up (`MASTER_Base`, `Box_Lid`, `Wall_Frosted_Glass`,
`Clasp_tab`…) are English.
